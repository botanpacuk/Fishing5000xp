FISH XP 5000 — проект мода для Stardew Valley 1.6 / SMAPI 4.3.x

ЧТО ДЕЛАЕТ
- Заменяет обычное начисление опыта навыка рыбалки за улов на 5000 XP.
- Не меняет стандартные 5 XP от крабовых ловушек.
- Не меняет 250 XP от книг рыбалки.

ВАЖНО
Это исходный проект с автоматической сборкой, а не готовый мод: DLL появится после успешной сборки.
Совместимость с Android SMAPI 4.3.2.5 пока не проверена в игре. Перед тестом сделайте копию сохранения.

КАК ПОЛУЧИТЬ ГОТОВЫЙ ZIP ЧЕРЕЗ GITHUB (С ТЕЛЕФОНА ТОЖЕ МОЖНО)
1. Откройте https://github.com и войдите в аккаунт или создайте его.
2. Создайте новый репозиторий (New repository), например FishXP5000. Можно выбрать Public.
3. Распакуйте этот архив. Загрузите ВСЁ содержимое папки FishXP5000 в корень репозитория, сохранив структуру папок.
   Важно: должна загрузиться скрытая папка .github/workflows с файлом build.yml.
4. Откройте вкладку Actions в репозитории.
5. Выберите workflow "Build Fish XP 5000" и нажмите Run workflow. Если workflow уже запустился после загрузки файлов, дождитесь его завершения.
6. Когда выполнение станет зелёным (Success), откройте его и внизу страницы скачайте Artifact
   "FishXP5000-Android-test". Это ZIP с DLL и manifest.json.
7. Распакуйте скачанный ZIP. Папку FishXP5000 переместите в Stardew Valley/Mods на устройстве.

ЕСЛИ СБОРКА НЕ УДАЛАСЬ
Откройте неудачный запуск в Actions и пришлите скриншот красной ошибки или скачайте лог.
Не устанавливайте архив исходников как мод: SMAPI нужен именно FishXP5000.dll.

ТЕХНИЧЕСКОЕ ПРИМЕЧАНИЕ
Проект использует Pathoschild.Stardew.ModBuildConfig 4.2.0 и .NET 6. Итоговую совместимость
с конкретной сборкой Android SMAPI можно подтвердить только запуском игры и проверкой SMAPI log.
