# Как собрать Fish XP 5000 на GitHub с телефона

1. Создайте репозиторий на [GitHub](https://github.com).
2. Загрузите в него всё содержимое этой папки, включая скрытую папку `.github`.
3. Откройте **Actions** → **Build Fish XP 5000** → **Run workflow**.
4. Дождитесь зелёного статуса **Success**.
5. Откройте запуск и скачайте артефакт **FishXP5000-Android-test**.
6. Распакуйте ZIP. Внутри будет папка `FishXP5000` с `FishXP5000.dll` и `manifest.json`.
7. Переместите эту папку в `Stardew Valley/Mods`.

Если сборка упадёт, пришлите скриншот ошибки из **Actions**. Это исходный проект; работоспособность на Android SMAPI 4.3.2.5 ещё нужно проверить в игре.
